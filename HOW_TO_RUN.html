🔧 Troubleshooting

  • ❌
    "Login failed. Check credentials."
    → Backend is not running. Open START_BACKEND.bat first, wait 3 seconds, then try login.
  • ❌
    Backend crashes with "unique constraint" error
    → Run SEED_DATABASE.bat to clean and re-seed. This deletes old corrupted data.
  • ❌
    Frontend shows blank white page
    → Wait 30 seconds for React to compile. Check the frontend terminal for "Compiled successfully".
  • ❌
    Port already in use
    → Run: taskkill /f /im node.exe then restart.
  • ❌
    WatsonX 404 error (AI returns mock)
    → Normal! IBM WatsonX Orchestrate URL doesn't support text generation. AI falls back to intelligent mock responses automatically.
